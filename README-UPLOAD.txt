RAHMAD PORTFOLIO — RESPONSIVE FULL PACK
=====================================

Isi paket:
- index.html
- script.js
- styles.css

PENTING SEBELUM UPLOAD
----------------------
1. Buat salinan/backup tiga file lama dari repository GitHub.
2. Upload/replace hanya index.html, script.js, dan styles.css di root repository.
3. Jangan hapus atau menimpa folder assets/images yang sudah kamu isi.
4. Setelah GitHub Pages selesai deploy, buka website dan tekan Ctrl+F5.

PERUBAHAN YANG DIMASUKKAN
-------------------------
- Layout lebar mengikuti viewport pada layar sangat lebar/zoom out (tanpa ceiling 140rem).
- Penyesuaian grid desktop, tablet, dan mobile.
- Menu dan modal tetap menggunakan struktur yang sudah ada.
- Workflow Strip "Pendekatan Kerja" yang sebelumnya diminta dihapus sudah dikeluarkan dari index.html.
- Detail proyek SDI memakai Web-1.png sampai Web-5.png (Web-6 dihapus karena belum ada di daftar file yang ditunjukkan).
- Kesalahan koma pada media Bekantan diperbaiki.
- Popup sertifikat satu sistem untuk Data Management Staff, Perkantoran, Programming R, dan Gemini.
- BNSP tetap ditampilkan sebagai dokumen dalam proses karena file sertifikatnya belum tersedia.
- Halaman sertifikat dapat diklik untuk diperbesar melalui lightbox.
- Warna bagian Expertise dibuat lebih konsisten pada kedua tema.
