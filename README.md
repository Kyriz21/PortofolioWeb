# Rahmad Rizky Fauzi — Portfolio Website

Static portfolio website for GitHub Pages.

## Main files

- `index.html` — website content and page structure
- `styles.css` — layout, colors, responsive behavior, modal and lightbox styling
- `script.js` — interactions, project details, certificate popup, filters and UI behavior

## Asset folders

- `assets/images/foto-profil.jpeg` — profile photo
- `assets/images/projects/` — project thumbnails and detail screenshots
- `assets/images/certificates/` — certificate cover/pages
- `assets/images/visual-works/` — social media and visual design gallery

The directory structure and asset manifests are included. The original image binaries are not included in this archive because they were not available as local files in this conversation. Copy the original image files from your GitHub repository into the matching folders. Do not replace them with empty files.

## Run locally

Open `index.html` in a browser. For best parity with GitHub Pages, use a local static server (for example VS Code Live Server).

## Publish on GitHub Pages

Upload the contents of this folder to the repository root, merging the `assets/` directory with the existing `assets/` directory. Do not delete existing image files. Then commit and wait for GitHub Pages deployment.
